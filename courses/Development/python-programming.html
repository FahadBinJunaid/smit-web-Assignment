Course Overview

Learn Python programming from scratch and apply it to data science and AI projects. This course covers Python fundamentals, libraries like NumPy and Pandas, and practical applications in machine learning and data analysis.

Key Topics Covered

  • Python Basics: Syntax, data types, and control structures
  • Data Manipulation with Pandas
  • Numerical Computing with NumPy
  • Data Visualization with Matplotlib and Seaborn
  • Introduction to Machine Learning with Scikit-learn
  • Working with APIs and Web Scraping

Course Duration

12 weeks, twice a week, 2 hours each (48 hours total).
